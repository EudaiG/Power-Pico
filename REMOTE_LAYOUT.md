# Local Release Layout

This repository follows the upstream Power-Pico top-level structure. The
maintained local firmware is in `software/Power_Pico`; the `firmware` directory
contains upstream reference images and the Bootloader.

The Modern UI presents the power controls as `Fixed voltage` and `PPS control`
under the `Power control` menu. The internal page is named `Fixed Voltage Page`
to match its user-facing role.
